====================================================================================
・gitで初めて登録する場合
# gitのローカルリポジトリを作成する
git init

# ファイルをステージング環境にUPする
git add first.txt # 特定のファイル
git add .         # そのフォルダにあるすべてのもの

# ローカルリポジトリにコミットする
git commit
  -- エディタが立ち上がるので、コミットのメッセージを入力して保存する
  -- 変更内容の要約
  -- 空行
  -- 変更した理由


# ローカルPCのフォルダとリモートのリポジトリを結び付ける
git remote add origin git@github.com:alphonse2009/intro_git2.git

# デフォルトは鍵付きでコミットが必要になるので、鍵なしに設定する
git remote set-url origin https://github.com/alphonse2009/intro_git2.git

# リモートのリポジトリをコミットする
git push -u origin master

==================================================================================

# リポジトリの状態を確認できる
git status

　変更しているものがなければ、特には表示されない
　変更しているものがあれば、
　 modified:   first.txt
　のように表示される。
　赤字の場合：ステージング環境に反映されていない
　緑字の場合：ステージング環境に反映されている
　
# 変更されたものをステージング環境にUPする
git add .

# 変更された内容をdiffで表示してコミットする
git commit -v

# gitの変更履歴のコメントを表示する
git log


====================================================================================

# ステージング環境にファイルを追加する
git add second.txt

# 変更された内容をdiffで表示してコミットする
git commit -v

# リポジトリに登録されたファイルを削除する
git rm second.txt

=======================================================================================

# ローカルリポジトリにコミット
git commit -v
